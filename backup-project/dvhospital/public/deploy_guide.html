ขนาดประมาณ ~88 MB
💾 ไฟล์ฐานข้อมูลสำรองจริง: ไฟล์ database/hospital_db_backup.sql ได้รับการส่งออกแบบ Programmatic ล่าสุด ตรวจทานชุดคำสั่งโครงสร้างและรองรับตัวอักษรภาษาไทยสมบูรณ์แบบ (Charset: UTF-8) พร้อมติดตั้งแล้ว!

1 ขั้นตอนที่ 1: การนำฐานข้อมูลเข้าโฮสต์ (Database Setup)

  1. เข้าหน้าจัดการโฮสติ้งหลักของคุณ สร้างฐานข้อมูล MySQL และผู้ใช้งานฐานข้อมูลขึ้นมาใหม่
  2. มอบสิทธิ์การทำงานทั้งหมดให้กับผู้ใช้รายนั้นกับฐานข้อมูลตัวใหม่ (All Privileges)
  3. เปิดโปรแกรม phpMyAdmin ของเว็บโฮสต์ขึ้นมา เลือกฐานข้อมูลตัวใหม่ที่สร้างขึ้น
  4. ไปที่แท็บ Import (นำเข้า) กดเลือกไฟล์ database/hospital_db_backup.sql จากแพ็กเกจของเรา
  5. คลิกปุ่ม Import/Go ฐานข้อมูลทั้งหมดพร้อมโครงสร้างจะถูกนำเข้าอย่างปลอดภัยสมบูรณ์

2 ขั้นตอนที่ 2: อัปโหลดและแตกไฟล์โค้ดของระบบ

🚨 คำแนะนำด้านความปลอดภัย: ห้ามนำไฟล์หลักของ Laravel แตกไว้ในโฟลเดอร์ public_html โดยตรงทั้งหมด เพื่อป้องกันการดูดไฟล์ .env หรือซอร์สโค้ดควบคุมระบบความปลอดภัย

📌 วิธีที่ A: สำหรับ Shared Hosting (cPanel / DirectAdmin)

  1. นำไฟล์ dvhospital_shared_production.zip อัปโหลดไว้ที่โฟลเดอร์หลักนอก public_html (ตัวอย่างเช่นโฟลเดอร์บ้าน /home/username/)
  2. ทำการแตกไฟล์ (Extract) ออกมาที่จุดนั้น
  3. ย้ายเฉพาะไฟล์และโฟลเดอร์ที่อยู่ในโฟลเดอร์ public/ ของโปรเจกต์ ไปไว้ในโฟลเดอร์ public_html/ ของโฮสติ้งจริง
  4. เปิดไฟล์ public_html/index.php แก้ไขเส้นทางอ้างอิงให้ถูกต้อง: 
    // บรรทัดที่ 34 (แก้ไขเส้นทางให้ถอยกลับ 1 ระดับไปโฟลเดอร์ที่อยู่นอก public_html)
require __DIR__.'/../vendor/autoload.php';

// บรรทัดที่ 47
$app = require_once __DIR__.'/../bootstrap/app.php';

📌 วิธีที่ B: สำหรับ VPS / Dedicated Cloud (Ubuntu/CentOS)

  1. อัปโหลดไฟล์ dvhospital_vps_production.zip ไปไว้ที่โฟลเดอร์ /var/www/dvhospital
  2. รันคำสั่ง unzip dvhospital_vps_production.zip
  3. ดาวน์โหลดแพ็กเกจไลบรารี: composer install --no-dev --optimize-autoloader
  4. ชี้การทำ Virtual Host ใน Nginx หรือ Apache ให้หันโฟลเดอร์ไปหา /var/www/dvhospital/public
  5. เซ็ตค่าสิทธิ์การเข้าถึงไฟล์ (File Permissions): 
    chown -R www-data:www-data /var/www/dvhospital
find /var/www/dvhospital -type f -exec chmod 644 {} \;
find /var/www/dvhospital -type d -exec chmod 755 {} \;
chmod -R 775 /var/www/dvhospital/storage
chmod -R 775 /var/www/dvhospital/bootstrap/cache

3 ขั้นตอนที่ 3: ตั้งค่าตัวแปรสิ่งแวดล้อมจริง (`.env` Config)

  1. นำไฟล์ `.env.production` มาเปลี่ยนชื่อไฟล์เป็น `.env`
  2. เปิดแก้ไขและอัปเดตข้อมูลเชื่อมฐานข้อมูลและโดเมนจริงของคุณ: 
    APP_NAME="โรงพยาบาลเทพรัตนเวชชานุกูล"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.go.th # โดเมนหลักโรงพยาบาลของคุณ

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=ชื่อฐานข้อมูลบนโฮสต์ของคุณ
DB_USERNAME=ผู้ใช้งานฐานข้อมูลบนโฮสต์ของคุณ
DB_PASSWORD=รหัสผ่านเชื่อมฐานข้อมูลของคุณ
  3. สร้างความปลอดภัยให้กับการเข้ารหัส (APP_KEY):
    • VPS: รันคำสั่ง php artisan key:generate
    • Shared Hosting: สามารถสุ่มโค้ดตัวอักษร 32 หลักมาเซ็ตลงในช่อง APP_KEY= หรือใช้เว็บเจนเพื่อสร้างคีย์ได้ เช่น Laravel Key Generator

4 ขั้นตอนที่ 4: การเชื่อมโยงโฟลเดอร์ภาพประชาสัมพันธ์ (`storage:link`)

เนื่องจากเว็บแอปพลิเคชัน Laravel บันทึกข้อมูลข่าวประชาสัมพันธ์และแบนเนอร์ไว้ที่ storage/app/public แต่จะเข้าถึงผ่านเว็บบราวเซอร์ทาง public/storage ดังนั้นจำเป็นต้องทำให้โฟลเดอร์ลิงก์หากัน:

📌 สำหรับ VPS

รันคำสั่งเพียงขั้นตอนเดียวผ่านโปรแกรม SSH:

php artisan storage:link

📌 สำหรับ Shared Hosting (cPanel / DirectAdmin ที่รันคำสั่งไม่ได้)

เราได้พัฒนาตัวช่วยสำหรับเว็บโฮสติ้งจำกัดสิทธิ์มาให้แล้ว:

  1. เข้าสู่เบราว์เซอร์ไปที่โดเมนของคุณและเรียกไฟล์สคริปต์ตัวช่วย: https://yourdomain.go.th/storage_link.php
  2. กดปุ่มที่หน้าจอ "คลิกเพื่อเชื่อมต่อโฟลเดอร์ภาพ" ระบบโปรแกรมมิ่งจะเชื่อมโยงฐานโฟลเดอร์ให้เองอัตโนมัติทันที!
  3. สำคัญมาก: เมื่อสัญลักษณ์ข้อความสีเขียวแจ้งเตือนว่าทำสำเร็จแล้ว ให้กลับเข้าไปลบไฟล์ public/storage_link.php ออกจากเว็บเซิร์ฟเวอร์ของคุณทันที เพื่อความปลอดภัยของข้อมูลทั้งหมด

⚡ ขั้นตอนเสริมพิเศษสำหรับความเร็ว (VPS Only)

หากคุณรันระบบบน VPS แนะนำให้รันคำสั่งเหล่านี้เพื่อคอมไพล์การตั้งค่าและดึงไฟล์ความเร็วสูงสุดของโครงสร้างเว็บมาทำงาน:

php artisan config:cache
php artisan route:cache
php artisan view:cache
