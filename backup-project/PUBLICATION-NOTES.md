# Source archive

Source files copied from the local backup directory for publication. Original files on drive D: are unchanged.

This is a source archive, not a ready-to-run deployment backup. Real configuration, environment files, database dumps, runtime data, uploaded documents, photographs and unreviewed binary assets are excluded. Dependencies in vendor/node_modules and generated build directories are excluded; reinstall from the project manifests.

Literal credentials and private server addresses found in the publication copy were replaced with placeholders. Set up your own configuration outside Git before use. Some sensitive or diagnostic source files and database seeders are deliberately excluded. Review the manifest before attempting deployment.
