# IPD หอผู้ป่วยใน

เปิด `/ipd` หรือเลือก IPD จากเมนูด้านข้าง บัญชีหอผู้ป่วยในจะเปิดหน้านี้อัตโนมัติหลังเข้าสู่ระบบ

## แดชบอร์ดรวม

เปิด `/ipd-dashboard` หรือเมนู IPD → ภาพรวม IPD เลือกปีงบประมาณ หอผู้ป่วย และเวรสำหรับยอดคงพยาบาล แล้วกดแสดงข้อมูล

- รับใหม่/จำหน่าย/เสียชีวิตสะสม: รวมทุกเวร ตั้งแต่ 1 ตุลาคมถึงวันนี้ หรือวันสิ้นปีงบประมาณสำหรับปีย้อนหลัง
- คงพยาบาลและสัดส่วนประเภท: ใช้วันล่าสุดที่มีรายงานของเวรที่เลือก ภายในช่วงปีงบประมาณ แสดงจำนวนหอที่มีรายงาน ไม่ดึงรายงานต่างวันมารวมกัน
- กราฟคงพยาบาลเฉลี่ยรายเดือน: เฉลี่ยเฉพาะวันที่มีรายงานครบทุกหอที่เลือกในเวรเดียวกัน เวรอื่นไม่ถูกนับซ้ำ เดือนที่ไม่มีวันข้อมูลครบแสดงขีด
- Productivity: ชั่วโมงการพยาบาลที่ต้องการ ÷ ชั่วโมงกำลังคนรวม ของรายงานเวรล่าสุด ไม่ใช่ค่าเฉลี่ยเปอร์เซ็นต์แต่ละหอ
- อัตราครองเตียง วันนอนเฉลี่ย และอุบัติการณ์ที่แบบฟอร์มยังไม่เก็บ แสดงขีดพร้อมคำอธิบาย ไม่มีข้อมูลสมมติหรือเกณฑ์ผ่านที่ยังไม่ได้กำหนด
- คลิกชื่อหอในตารางเพื่อเปิดรายงานตามวัน/เวรล่าสุด หรือใช้ปุ่มบันทึกหอเพื่อเปิดฟอร์มของวันนี้

เมื่อนำไปติดตั้งเครื่องอื่น ให้นำ `ipd-dashboard.php` และ `ipd-layout.php` ไปด้วยพร้อมไฟล์ PHP/CSS/JS รุ่นนี้ ไม่ต้องปรับโครงสร้างฐานข้อมูลสำหรับแดชบอร์ด


## บัญชีและสิทธิ์

| บัญชี | บทบาท | ขอบเขต |
|---|---|---|
| ipd_male_head | หัวหน้าหอ | อ่าน/บันทึกหอผู้ป่วยชาย |
| ipd_male_staff | ผู้บันทึก | อ่าน/บันทึกหอผู้ป่วยชาย |
| ipd_female_head | หัวหน้าหอ | อ่าน/บันทึกหอผู้ป่วยหญิง |
| ipd_female_staff | ผู้บันทึก | อ่าน/บันทึกหอผู้ป่วยหญิง |
| ผู้บริหาร / หัวหน้ากลุ่มงานเดิม | executive / director | อ่านตามขอบเขตหน่วยงาน; all อ่านทั้งสองหอ |
| ผู้ดูแลระบบเดิม | admin | จัดการบัญชี และอ่าน/บันทึกตามขอบเขตหน่วยงาน |

รหัสผ่านเริ่มต้นแบบสุ่มอยู่ใน `.private/ipd-accounts.txt` บังคับเปลี่ยนเมื่อเข้าสู่ระบบครั้งแรก ผู้ดูแลระบบเพิ่ม/แก้ไข/ปิดบัญชีได้ที่ `/users` เลือกหน่วยงาน `ipd_male` หรือ `ipd_female` ไม่มีการเพิ่มสิทธิ์ให้บัญชีหน่วยงานอื่นอัตโนมัติ

## วิธีนับ

- วันที่เป็นวันที่เริ่มเวร ใช้เวลาไทย เช้า 08–16 บ่าย 16–00 ดึก 00–08
- แยกรับเข้าและจำหน่ายตามประเภทผู้ป่วย 1–4 ประเภทเมื่อรับเข้า/จำหน่ายอาจต่างจากประเภท ณ สิ้นเวรได้
- คงพยาบาล = ยกมา + รับใหม่ + รับย้าย − (Refer + OPD case + Emergency case + ย้ายออก + ไม่สมัครใจอยู่ + เสียชีวิต + กลับบ้าน)
- Refer, OPD case, Emergency case เป็นรายการแยกกัน ไม่ใช่ยอดรวมกับยอดย่อย แต่ละเหตุการณ์จำหน่ายต้องลงเพียงรายการเดียว
- ห้องสามัญ + ห้องแยก ณ สิ้นเวร ต้องเท่ากับคงพยาบาล ทารกแรกเกิดนับรวมในยอดห้องแล้ว คาสายสวนเฉพาะเด็กเป็นส่วนหนึ่งของคาสายสวนทั้งหมด
- ยอดรับใหม่สะสมรวมทุกเวร ตั้งแต่ 1 ตุลาคมถึงวันที่เลือก ไม่รวมยอดยกมา/รับย้าย กราฟคงพยาบาลแสดงเวรเดียวกันย้อนหลัง 7 วัน วันไม่มีรายงานแสดงขีด
- Productivity = ชั่วโมงการพยาบาลที่ต้องการรวม ÷ (จำนวนพยาบาล × ชั่วโมงทำงานต่อคน) × 100 ต้องกรอกชั่วโมงตามเกณฑ์ที่หน่วยงานใช้ ไม่มีการสมมติน้ำหนักหรือเป้าหมาย
- บันทึกลง reports และ report_history ใน MySQL ใช้เลขฉบับป้องกันการบันทึกทับพร้อมกัน ไม่มี workflow รับรองในโมดูลนี้

## ติดตั้งเพิ่มบนเครื่องอื่น

นำไฟล์ ipd.php, ipd.js, ipd.css, install-ipd.php และไฟล์ security.php, reports-api.php, app.js, schema.sql รุ่นนี้ไปด้วย จากนั้นใช้บัญชีติดตั้งฐานข้อมูลรัน `php install-ipd.php` เพียงครั้งแรก สคริปต์รันซ้ำได้ ไม่รีเซ็ตรหัสผ่านหรือข้อมูลเดิม ไม่ต้องรัน setup-users.php ซ้ำ
